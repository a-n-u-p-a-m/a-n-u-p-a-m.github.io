Q5 — Data Dictionary Tool

Generate a table–table relation diagram and a printable HTML/PDF data dictionary from schema input (JSON/XML).

Input — Schema (JSON)

Accepted formats: JSON (preferred). XML accepted if it follows logical structure — upload and you'll be prompted.

How to generate schema JSON from your DB

  1. For MySQL/Postgres: run `pg_dump --schema-only` or `mysqldump --no-data` and extract `CREATE TABLE` statements.
  2. Convert SQL DDL to JSON using simple scripts (example below). A sample SQL->JSON helper is described below.
  3. JSON format expected: { "tables":[{ "name": "...","description":"...","columns":[{ "name","type","pk", "nullable","desc"}]},...],"relationships":[{"from":"table.col","to":"table.col","type":"1:1"}] }
Tip: The sample JSON loaded via Load Sample JSON shows exact format.
